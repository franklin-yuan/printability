Connect OpenAI

The local Printy helper holds your API key. This extension stores only a connection code.

  1. Double-click Start Printy.vbs in the Printy helper folder.
  2. Enter your OpenAI API key in that helper and save it.
  3. Set the helper’s extension ID to .
  4. Copy the helper’s connection code below.

Printy collects available logs on the Printers page before AI summaries. Automatic major-change notifications send printer status, current/recent filenames, filament data and captured evidence to OpenAI, at most 20 automatic requests per day and five minutes apart. You can disable automatic notifications in Settings or request a manual summary. API usage is billed to your OpenAI account.
