Printability connection

This page only connects the local helper for USB lights and Printability Voice. Printer assignments and light setup are in the Printability panel’s Settings tab on the 3DPrinterOS Printers page.

  1. Double-click Start Printability.vbs in the Printability helper folder.
  2. Set the helper’s extension ID to and save. Add your xAI API key for Printability Voice.
  3. Copy the helper’s connection code below.
  4. For lights, connect the S3 USB port in the helper, then enable hardware in Printability Settings.

Lights and local notifications are free of API calls. Printability Voice uses your xAI API account while connected. Start voice explicitly and stop it when finished. OpenAI is no longer used.
